# 机械臂 FK 标定夹具：锥座孔板（拓竹 A1 打印）

这套夹具用于"枢轴测试 + 已知孔距"的机械臂正运动学（FK）标定，使用**锥座版**，所有零件都可以在 **拓竹 A1**（打印尺寸 256 × 256 × 256 mm）上打印，打印出来就能用，不需要额外装配。

- **枢轴约束**：探针球头放进同一个锥座时，球心是一个固定点。机械臂换不同姿态后，FK 算出的球心位置之间的离散程度就是 FK 误差。
- **尺度约束**：几个锥座之间的距离实测已知，用来确定整体尺度，因为只靠单孔枢轴约束测不出尺度。

---

## 1. 文件清单

| 文件 | 用途 |
|---|---|
| `out/pivot_plate_cone.step` | **4 座孔板**（主零件），90° 锥座直接打印出来 |
| `out/pivot_seat_cone.step` | **单个锥座块**（44 × 30 mm），用于单孔枢轴测试，或者垫高后增加 z 方向的激励 |
| `out/*_cone.stl` | 与上面一一对应的 STL，Bambu Studio 导入 STEP 出问题时备用 |
| `make_pivot_parts.py` | 参数化生成脚本（CadQuery） |
| `check_clearance.py` | 校验脚本：重新导入 STEP 检查实体有效性和打印尺寸，并扫描探针倾角做碰撞检查 |

`out/` 目录里还有 `*_triball` 文件，那是三球座版（见第 8 节），用锥座版的话可以忽略。

## 3. 几何与坐标

```
 y
 ▲   H3 ●───────────── 190 ─────────────● H4
 │      │                               │
 │     140         FK PIVOT PLATE      140
 │      │                               │
 │   H1 ●──➤──────────  190 ────────────● H2
 └──────────────────────────────────────────► x
```

- 孔板尺寸为 240 × 190 × 6 mm。座凸台为 Ø18 × 10 mm，凸台顶面距板底 16 mm。
- 锥座是 90° 锥孔，锥口直径 9 mm，深 4.5 mm，凸台顶边倒角 1.5 mm。
- **孔板坐标系**：原点在孔板左下角（H1 那个角），x 轴沿刻印箭头方向（H1 → H2），y 轴指向 H3，z 轴朝上。
- **名义座中心坐标**（mm）：

| 座 | x | y |
|---|---|---|
| H1 | 25 | 25 |
| H2 | 215 | 25 |
| H3 | 25 | 165 |
| H4 | 215 | 165 |

- **名义孔距**：H1–H2 = H3–H4 = 190 mm；H1–H3 = H2–H4 = 140 mm；两条对角线均为 236.01 mm。
  ⚠️ **这些只是设计值。标定时必须用打印后实测的孔距**（见第 6 节）。FDM 打印在 200 mm 尺度上的尺寸误差通常有零点几毫米。
- 4 个 Ø6.6 的通孔位于四边中点，可以用 M6 螺丝固定到台面或光学面包板上；也可以直接用 C 形夹压住板边。

## 4. 探针与适配范围

探针要短而粗（总长 50–150 mm），刚性固定在法兰上；带灵巧手标定时，固定在手掌或手腕的刚性部位，手指锁死。

用 `check_clearance.py` 得到的结果如下。"最大倾角"指探针杆相对竖直方向倾斜多大角度时，还不会碰到锥座（脚本最高只测到 85°）：

| 球径 | 杆径 | 球心高于凸台顶面 | 最大倾角 |
|---|---|---|---|
| Ø6 | Ø3 / Ø4 | −0.23 mm | 65° / 60° |
| **Ø8** | **Ø4 / Ø6** | 1.19 mm | **75° / 65°** |
| Ø10 | Ø6 / Ø8 | 2.60 mm | 85° / 70° |
| Ø12 | Ø8 | 4.02 mm | 85° |

- 推荐配置：**Ø8 球头 + Ø4–6 杆**。
- 适用的球径上限约为 Ø12.7。再大的话，球会搭在锥口边缘上，而不是贴在锥面上。
- 采集时让探针倾角保持在 **60° 以内**，各种配置都有足够余量。

## 5. 在拓竹 A1 上打印

在 Bambu Studio 里**直接导入 STEP**（如果有问题就导入同名 STL），按文件原来的朝向平放，**底面贴着热床，不需要支撑**。锥孔开口朝上，螺丝孔是竖直的。

| 项目 | 推荐值 |
|---|---|
| 材料 | **PLA**（Bambu PLA Basic / Matte）。比 PETG 刚性更好、翘曲更小；也可以用 PLA-CF |
| 热床 | 纹理 PEI 板，打印前用酒精擦干净 |
| 喷嘴 / 层高 | 0.4 mm / **0.16 mm**（锥面更平滑）。也可以用 0.2 mm，再对凸台区域开可变层高，把锥面那几毫米降到 0.08–0.12 mm |
| 墙层数 | 4 |
| 顶 / 底层数 | 6 / 4 |
| 填充 | 30% 螺旋体（Gyroid） |
| 裙边（Brim） | 孔板建议加 5 mm 外裙边，防止边角翘起（已确认加裙边后仍在 A1 范围内） |
| 冷却 | 默认即可 |

- 孔板大约需要 150–200 g 耗材（按 30% 填充估算，以切片软件显示为准）。
- 打印完成后，**等热床完全冷却再取下孔板**，避免板子变形。
- 单个座块可以和孔板一起摆盘，也可以单独打印。
- 取下后检查锥孔里有没有拉丝或残渣，有的话用小刀或棉签清理干净，**不要打磨锥面**。

## 6. 实测孔距（必须做）

1. 把两颗**同直径**的钢珠分别放进要测的两个锥座里。
2. 用数显卡尺外量爪**轻轻**夹住两颗钢珠的外侧，读数减去一个钢珠直径，就是这两个座的球心距离。
3. 每对座测 3–5 次取平均。至少测 **H1–H2、H1–H3、H2–H4、H3–H4** 这四条边。如果有 300 mm 卡尺，再测两条对角线。
4. 把实测值记到下表，标定时**用实测值**：

| 座对 | 名义 (mm) | 实测 1 | 实测 2 | 实测 3 | 平均 |
|---|---|---|---|---|---|
| H1–H2 | 190.00 | | | | |
| H3–H4 | 190.00 | | | | |
| H1–H3 | 140.00 | | | | |
| H2–H4 | 140.00 | | | | |
| H1–H4 | 236.01 | | | | |
| H2–H3 | 236.01 | | | | |

> 只要所有锥孔的规格相同，测出来的球心距离就和用来测量的钢珠大小无关。
> PLA 的热膨胀系数约 70 ppm/K，温差 5 K 时 200 mm 只变化约 0.07 mm，可以忽略。但**测孔距和标定最好在同一个房间、同一天完成**。

## 7. 使用流程

1. **固定孔板**：放在任务区域里，用 M6 螺丝或 C 形夹压紧，确认板子不会翘动。
2. **预热机械臂**：空跑 15–30 分钟。
3. **装探针**：负载状态要和实际使用一致，比如带着灵巧手。
4. **采集数据**，对每个锥座：
   - 切到拖动或自由驱动模式。把球头放进锥座里**轻轻按一下让它贴合，然后松手，等 1 秒**，读取**编码器关节角**（连续读几十帧取平均）。
   - 每个座采 **10–15 个姿态**：探针向各个方向倾斜（60° 以内），绕探针轴线转一整圈，尽量切换肘部和腕部构型，**让每个关节都转过较大的角度**。
   - 留出 20% 的姿态，或者整个留出一个座，作为验证数据。
5. **处理数据**：先用名义 FK 做单座枢轴拟合，得到基线误差；再把关节零位、针尖偏移、各座中心，加上**实测孔距约束**放在一起做最小二乘优化；用 SVD 检查可观测性；最后在验证集上比较标定前后的误差。
6. **增加 z 方向激励（可选）**：孔板上的 4 个座都在同一个平面里。可以把单锥座块垫到一个已知高度的量块上，或者放到另一个高度，再采一组数据。

### 锥座版的使用注意

PLA 锥面比较软，使用时要注意：

- **只能轻按**：让球头贴合锥面即可，不要用力往下压，否则会在锥面上压出凹坑，也会让读数偏移。
- **记录前一定要松手**：按着时机械臂和探针都在受力变形，读数不准。
- **定期检查重复性**：每次标定前，在同一个座上用同一个姿态放 5 次，看 FK 算出的球心离散程度。如果明显比以前大，说明锥面已经磨损，重新打印孔板（孔距要重新实测）。
- **保持清洁**：锥孔里不要有灰尘或碎屑，用之前可以吹一下。

## 8. 可选升级：三球座版

如果以后锥座磨损得快，或者想要更高的重复性，可以改用 `out/pivot_plate_triball.step` 和 `out/pivot_seat_triball.step`。外形和锥座版完全一样，只是每个座改成由 3 颗 Ø6 钢珠组成的运动学支撑（金属对金属接触，不磨损）：

- 孔板需要 12 颗 Ø6 钢珠，每个单座块需要 3 颗。用环氧胶或 CA 胶粘进球窝，用平整金属片把 3 颗同时压到底，确保接触面上没有胶。
- 球窝直径设计为 6.2 mm。如果钢珠放不进去，把 `SUPPORT_POCKET_D` 调大 0.1–0.2 mm 重新生成。
- Ø8 球头 + Ø6 杆在三球座上的最大倾角约 80°。

## 9. 修改与重新生成

```bash
pip install cadquery
python make_pivot_parts.py      # 生成 out/*.step 和 out/*.stl
python check_clearance.py       # 检查实体有效性、A1 尺寸，并扫描探针倾角
```

常用参数都在 `make_pivot_parts.py` 开头：

| 参数 | 含义 | 默认值 |
|---|---|---|
| `PLATE_L, PLATE_W, PLATE_T` | 孔板长、宽、厚 | 240, 190, 6 |
| `SEATS` | 各座中心坐标 | 见第 3 节 |
| `BOSS_D, BOSS_H` | 座凸台直径、高度 | 18, 10 |
| `CONE_TOP_R` | 锥口半径（90° 锥，深度等于半径） | 4.5 |
| `MOUNT_HOLES, MOUNT_D` | 固定孔位置和直径 | 四边中点 / 6.6 |

改了孔板尺寸之后，记得把加上裙边后的外形控制在 **246 × 246 mm 以内**（A1 打印范围 256 mm 减去两边各 5 mm 裙边），并重新运行 `check_clearance.py`。
